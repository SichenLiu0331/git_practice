# Unit converter

This program converts a temperature from Celcius to Fahrenheit.

## Installation

- Python 3
- Pytest
- a terminal

## Usage

1. change into the project directory
2. run python3 convert.py
3. type a temperature

The course page is on the [TUM](https://www.tum.de) website.

To run, use `python3 convert.py` with the `convert.py` file.
